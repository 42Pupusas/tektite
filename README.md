# tektite

Obsidian-style Markdown renderer for [egui](https://github.com/emilk/egui), powered
by [marki-parse](https://crates.io/crates/marki-parse), a zero-copy CommonMark/GFM
parser.

```no_run
use tektite::MarkdownView;
```

Fully CommonMark-compatible, with GFM tables and Obsidian-flavoured styling.
